# 발표 대본 — 시연 화면을 보며 말하기 (키워드판)

화면: Webots 3D 뷰 + 지도 Display + 콘솔. 지도 색: 검정 벽 · 흰 빈칸 · 회색 미지 · 파란 점 로봇 · 빨간 별 목표 · 노란 삼각형 사과 추정 · 검정 원 카메라로 찍은 낮은 장애물.

## 0. 시작 (그림, 30초)

![상태 기계](images/state_machine.png)

- 여섯 상태 순서: EXPLORE → VISIT → CONFIRM → APPROACH → RETURN → DONE
- EXPLORE: 지도 경계로 이동 + 카메라 사과 검사 동시. 사과 보이면 즉시 VISIT
- VISIT: 사과 0.7 m 앞까지 · CONFIRM: 멈춰 재확인, 아니면 제외 후 탐색 복귀
- APPROACH: 0.35 m 접근 · 1개째면 EXPLORE로 돌아가 두 번째 · 2개 방문 → RETURN → DONE
- 콘솔 첫 칸에 상태 이름이 실시간으로 찍힘 → 그걸 보며 설명
- Webots 전환, ⏩(fast) 누름. 첫 3초 정지는 정상

## 1. 화면 순서대로

| 시뮬 시각 | 화면 | 키워드 |
|---|---|---|
| 0 ~ 4 s | 3초 정지 후 출발 | LiDAR 스캔 3장 모아 지도 → 첫 목표. 예전 버그: 스캔 없이 목표 골라 즉시 '탐색 완료' |
| 5 ~ 60 s | 빨간 별(목표)로 이동 | frontier = 빈칸과 미지의 경계. 거리 = 직선 아님, 실제 경로거리(BFS) → 벽 너머 가짜 목표 제거. 발견 381 s → 234 s. 가까운 것 우선 + 도착 전 목표 안 바꿈 → 한 방 다 보고 나감 |
| 회전할 때 | 제자리 한 바퀴 | 의도한 동작. LiDAR 360° vs 카메라 60°. 주변 2 m 안 카메라 미확인 120칸 이상 → 한 바퀴(5 s, 25 s 쿨다운). 로그 `둘러보기=` |
| 88 s, 105 s | 지도에 검정 원 = 초록 사과 | LiDAR 높이 17 cm, 사과 10 cm → 지도에 안 잡힘. 카메라 색+원형 → 반경 20 cm 장애물 직접 찍음. 실패담: 표시가 1초 만에 지워짐(LiDAR 빈칸 통과) → 보라 사과 충돌 → 고정 마스크 → 접촉 0 |
| 163.8 s | 3초 후진 | 헛바퀴 감지. LiDAR 아래 물체에 걸림. 앞뒤 거리 2초간 불변 → 슬립 판정 → 위치 되돌림 + 그 자리 지도 표시. 1차 버전은 복도에서 오작동(전체 빔 중앙값) → 앞뒤 빔만 |
| 203.3 s | ★ 사과 발견 → VISIT | 색만으론 소화기·캔·스티커 전부 사과. 5단계: ① HSV 빨강, 채도 160↑ ② 원형도 0.70↑(카탈로그에서 캔·스티커 0.45~0.50 → 임계 상향) ③ 물체 종횡비 0.65~1.5, 밖 빨강 10%↓ ④ 수평선 아래 + 반지름 거리·세로위치 거리 2배 안 일치 ⑤ 2프레임 연속. 117개 물체 오탐 0. YOLO는 시뮬 사과 미분류 → 제외. 발견 즉시 탐색 중단 |
| 218 ~ 223 s | 0.7 m 정지·회전 → 0.35 m 접근 | 재확인 0.7 m: 카메라 높이 8.8 cm, 시야 60° → 0.4 m에선 사과가 화면 아래로 벗어남(실패 후 수정). 마지막 0.35 m는 DWA 끄고 단순 추종(도킹) — 벽 11 cm 옆 사과에 DWA 안전거리로 접근 불가(오프라인 재현으로 확정). 정석 이탈은 이 구간 하나 |
| 223 s ~ | 방문 사과에 검정 원, 다시 EXPLORE | 방문 사과도 장애물 고정 → 밟지 않음. 규칙상 2개 필수 → 탐색 계속 |
| 283 s | 딴 데 갔다 돌아옴 | 빨간 후보 조사: 형태 검사 탈락한 바닥 빨간 덩어리 = 가려진 사과 가능성 → 가까우면 1 m 앞 4초 관찰. 아니면 영구 제외 |
| 533 s | ★ 두 번째 사과 (1 m 안) | 가구에 가려 0.9 m 안에서만 보임(완주 4회 공통). 카메라 '봤다' 인정 거리 2.0 → 1.2 m로 축소 → 가까이 다시 지나감 |
| 541 s | 방문 2/2 → RETURN | 복귀 = 완성된 지도로 A* 한 번 |
| 582 s | 복귀 완료, DONE | 복귀 오차 0.11 m. 위치 추정 = 엔코더 + 나침반 + LiDAR 상관 스캔 매칭 → 전체 오차 0.19 m 이내. 접촉 0. 개발 월드만 Supervisor 진실값 비교, 제출 월드는 순수 센서 |

## 2. 예상 밖 상황

| 화면 / 로그 | 키워드 |
|---|---|
| 15초 멈춤 → 후진 (`국소 정체`) | 정체 감시. DWA가 벽 0.45 m 앞에서 멈추던 원인 = LiDAR 잡음 1.5 cm vs 5 cm 셀 8연속 판정(오프라인 재현: 잡음 없으면 정상, 있으면 궤적 87~96% 탈락). costmap 기반으로 전환 → 정지 33% → 9% |
| 보행자 통과 (`동적점` 증가) | 지도에 없는 점 = 움직이는 것 → 여유 0.20 m로 회피. 자취는 지도에 안 남음 |
| 사과 아닌 곳 → 돌아옴 (`재확인 실패`) | CONFIRM = 오탐 필터. 위치 블랙리스트 |
| 한 자리 오래 헤맴 | 좁은 방(문 0.4 m) 한계: 팽창 후 목표 없음. 다음 단계 |
| SEARCH 상태 | LiDAR 지도 완성 ≠ 카메라 탐색 완료. 문 너머로 훑은 방 건너뛴 실행 있었음 → frontier 없으면 카메라 미확인 칸 수색 |

## 3. 마무리 (10초)

- 다섯 가지 모두 실패 → 지도 저장 → 오프라인 재현 → 원인 수치 확정 → 해당 단계 기준만 수정
- 정석 파이프라인(위치추정·점유격자·frontier·A*·DWA) 유지. 이탈은 마지막 0.7 m 도킹 하나
